# データ調査メモ

## 採用方針

- デモ保証エリアは江東区を第一候補にする。
- 現在地モードはGPS中心表示を行い、データが少ない場合はバナーで江東区モードを案内する。
- 外部CSV/APIはCORSとキャッシュ制御のため、最終的にはCloudflare Workers経由に寄せる。
- 実データ接続後もデモが止まらないよう、取得失敗時は同じ型のモックデータへフォールバックする。

## 技術上の注意

- OpenRouteServiceはAPIキーが必要。フロントエンドへ直接埋め込まず、Workerの環境変数 `ORS_API_KEY` で管理する。
- Nominatimはオートコンプリート用途に使わない。検索ボタン押下など、ユーザーが確定した入力だけを問い合わせる。
- WBGTは出典として環境省熱中症予防情報サイトを明記する。
- 空き状況更新はデモ用簡易認証。本番では施設ごとの認証・権限管理が必要。
- 東京都系CSVはShift_JISのため、WorkerでUTF-8へ変換してからフロントへ返す。
- 建物日陰レイヤーは江東区デモ限定の参考表示。PLATEAU 3D都市モデルの江東区建築物LOD1 2025から、東陽町〜木場〜南砂周辺の建物矩形・高さを抽出して使用する。現時点では固定日時の影ポリゴンを表示し、緑陰スコアには未反映。
